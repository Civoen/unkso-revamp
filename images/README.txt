UNKSO images
============

Upload images to this folder using exactly these filenames. Each one appears on
the site as soon as it is uploaded; until then the striped placeholder shows.
In GitHub: open this folder, choose Add file > Upload files, then Commit.
Cloudflare Pages redeploys automatically a minute or so later.

Filenames are lower case and must match exactly (card-bravo.jpg, not Card-Bravo.JPG).

TIPS
  - Save as .jpg and keep each file under ~300 KB (squoosh.app is free and quick).
  - Darker images work best: the site lays a dark fade over them so the white
    text stays readable.
  - Use your own screenshots and clan footage rather than official game artwork.
